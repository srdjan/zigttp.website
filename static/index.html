zigttp expert writes inside the provable zigts subset. Each draft is compiled, proof errors become the next repair step, and verified patches are handed back for review.

  • Every patch is compiled and proven, not just generated.
  • Unsupported patterns return as compiler errors with fixes.
  • You review handlers that already passed the proof loop.

How the loop closes

  1. 01 Write

    The agent drafts a zigts handler from your request.

  2. 02 Compile

    It runs the same compiler that gates local deploys.

  3. 03 Read proof errors

    Unsupported or unproven code returns as diagnostics.

  4. 04 Rewrite

    It edits against diagnostics and recompiles until clear.

  5. Proven

    Every obligation discharged before the code reaches you.

compile, read, rewrite - repeat until proven

ordinary agent

Generates code, then hopes tests catch what it got wrong. The gaps surface in production.

zigttp expert

Compiles every draft and fixes against the compiler's own proof errors. The gaps surface before review.

zigttp expert is a terminal coding agent with native tool-use into the zigttp compiler, token accounting, and per-session budgets. It writes only inside zigts, so every patch stays in the provable subset.

Core pillars

The product in four parts.

01

Provable subset

zigts keeps TypeScript small enough for exhaustive compile-time analysis.

02

Native module surface

22 native zigttp:* modules expose env, crypto, routing, validation, cache, SQL, fetch, WebSocket, and more.

03

Contract-aware deploy

Deploy emits a local self-contained binary, appends a proof ledger row, and signs an attestation by default.

04

Agent-ready loop

zigttp expert repairs code against the same verifier that blocks unsafe patches.

CLI surface

One workflow from first save to review.

Use the same CLI to scaffold, prove on save, test, deploy locally, inspect the ledger, replay witnesses, and run the agent.

Getting started CLI reference Contracts and sandboxing Virtual modules Source Deck

Every deploy appends a contract verdict to proofs.jsonl:

safe safe_with_additions blocked needs_review 
# scaffold and prove on every save
zigttp init api && cd api
zigttp dev --watch --prove

# enforce the handler's active guarantees in CI
zigttp ratchet check src/handler.ts

# deploy a self-contained binary locally, with a ledger entry
zigttp deploy
zigttp proofs show HEAD

# keep regressions pinned
zigttp witnesses replay
zigttp expert "add health check"
