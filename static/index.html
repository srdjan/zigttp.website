The Loop

The agent edits inside the same proof system that rejects it.

zigts expert proposes a patch, runs it through -Dverify and -Dcontract, discharges your Spec<...> obligations, and stops at code it can certify. Counterexamples land in the witness corpus so a regression never sneaks past twice. No shell agent guessing around a separate compiler.

Run dev --watch --prove alongside it. Every save diffs the contract against the running version and only hot-swaps when the verdict is safe or safe_with_additions. Breaking changes block the swap and print the diff.

import { method, pathname, params } from "zigttp:router";

const getUser = (id: string) =>
    fetchSync(`https://api.example.com/users/${id}`)
    |> Response.json;

function handler(req) {
    return match (`${method(req)} ${pathname(req)}`) {
        "GET /"          => Response.json({ status: "ok" }),
        "GET /health"    => Response.json({ healthy: true }),
        "GET /users/:id" => getUser(params(req).id),
        "POST /echo"     => Response.json(req.body),
        _                => Response.json(
                                { error: "Not Found" },
                                { status: 404 }
                            ),
    };
}
import { parseBearer, jwtVerify } from "zigttp:auth";
import { schemaCompile, validateJson } from "zigttp:validate";
import { env } from "zigttp:env";

comptime(() => schemaCompile("user", JSON.stringify({
    type: "object",
    required: ["name", "email"],
    properties: {
        name:  { type: "string", minLength: 1 },
        email: { type: "string", format: "email" },
    }
})));

function handler(req: Request): Response {
    const token = parseBearer(req.headers["authorization"]);
    if (!token) return Response.json(
        { error: "unauthorized" }, { status: 401 }
    );

    const auth = jwtVerify(token, env("JWT_SECRET") ?? "");
    assert(auth.ok, Response.json(
        { error: auth.error }, { status: 401 }
    ));

    return match (req.method) {
        "POST" => {
            const result = validateJson("user", req.body ?? "");
            assert(result.ok, Response.json(
                { errors: result.errors }, { status: 400 }
            ));
            Response.json({ user: result.value }, { status: 201 });
        },
        _ => Response.json({ user: auth.value }),
    };
}

function TodoForm(): JSX.Element {
    return (
        <form hx-post="/todos" hx-target="#todo-list" hx-swap="beforeend">
            <input name="text" required="required" />
            <button type="submit">Add</button>
        </form>
    );
}

function TodoItem(text: string): JSX.Element {
    return <li class="todo">{text}</li>;
}

function handler(req: Request): Response {
    if (req.method === "GET") {
        return Response.html(renderToString(
            <main>
                <script src="https://unpkg.com/htmx.org@2.0.8"></script>
                <TodoForm />
                <ul id="todo-list"></ul>
            </main>
        ));
    }

    const todo = decodeForm("todo.create", req.body ?? "");
    assert(todo.ok, Response.text("bad request", { status: 400 }));
    return Response.html(renderToString(TodoItem(todo.value.text)));
}
import { guard } from "zigttp:compose";
import { parseBearer, jwtVerify } from "zigttp:auth";
import { env } from "zigttp:env";

distinct type Secret = string;
type Claims = { sub: string };
type AuthRequest = Request & { user?: Claims };
const jwtSecret: Secret = env("JWT_SECRET") ?? "";

const cors = (req: AuthRequest): Response | undefined =>
    match (req.method) {
        "OPTIONS" => Response.text("", {
            status: 204,
            headers: { "Access-Control-Allow-Origin": "*" }
        }),
        _ => undefined,
    };

const requireAuth = (req: AuthRequest): Response | undefined => {
    const token = parseBearer(req.headers["authorization"]);
    if (!token) return Response.json(
        { error: "unauthorized" }, { status: 401 }
    );
    const auth = jwtVerify(token, jwtSecret);
    if (!auth.ok) return Response.json(
        { error: auth.error }, { status: 403 }
    );
    req.user = auth.value;
    return undefined;
};

const dashboard = (req: AuthRequest): Response =>
    Response.json({ welcome: req.user?.sub ?? "guest" });

// Pipe: guards short-circuit, handler runs last
const handler = guard(cors) |> guard(requireAuth) |> dashboard;
import { run, step, waitSignal } from "zigttp:durable";
import { decodeJson } from "zigttp:decode";
import { schemaCompile } from "zigttp:validate";

comptime(() => schemaCompile("order", JSON.stringify({
    type: "object",
    required: ["item", "qty"],
    properties: {
        item: { type: "string" },
        qty:  { type: "number", minimum: 1 }
    }
})));

function handler(req: Request): Response {
    const body = decodeJson("order", req.body ?? "");
    assert(body.ok, Response.json(
        { errors: body.errors }, { status: 400 }
    ));

    return run(`order-${body.value.item}`, () => {
        const charge = step("charge", () =>
            fetchSync("https://pay.api/charge", {
                method: "POST",
                body: body.value
            })
        );
        // Wait for external webhook confirmation
        const confirm = waitSignal("payment-confirmed");
        return Response.json({
            status: "fulfilled",
            chargeStatus: charge.status,
            signal: confirm
        });
    });
}
import type { Spec } from "zigttp:types";
import { step } from "zigttp:durable";
import { decodeJson } from "zigttp:decode";

// Declare the obligations the compiler must discharge.
type Guardrails = Spec<
    "idempotent"
    | "deterministic"
    | "no_secret_leakage"
    | "injection_safe"
>;

function handler(req: Request): Response & Guardrails {
    const body = decodeJson("order", req.body ?? "");
    assert(body.ok, Response.json(
        { errors: body.errors }, { status: 400 }
    ));

    // `Date.now()` would trip -deterministic - wrap it in step().
    const ts = step("ts", () => Date.now());

    return Response.json({ id: body.value.item, ts });
}

// Build:  zigts check handler.ts --json
//   PROVEN Spec<idempotent, deterministic, no_secret_leakage, injection_safe>
// Drop the step() wrapper and the verifier raises ZTS500 with the
// per-property "Try:" suggestion. The studio chip flips red on save.

What Ships

One binary. Six moving parts.

zigts makes handlers analyzable; the rest is built on that constraint. 3ms init, 1.2MB binary, 4MB memory baseline.

01

Pure-Zig runtime

HTTP handlers on x86-64 and ARM64 with fast cold starts and zero-copy responses.

modules zigttp:io zigttp:http

02

zigts: the provable subset

Native TS + TSX, distinct types, generics, and match / guard / comptime where proof needs them.

modules zigttp:router zigttp:compose

03

Stacked compile-time proofs

Seven path proofs under -Dverify plus sound mode plus -Dcontract extraction plus discharge of every Spec<...> the handler declares. The classifier derives a least-privilege sandbox from the result.

modules zigttp:validate zigttp:decode zigttp:types

04

Studio: the browser proof workbench

zigttp studio re-verifies on save and shows the verdict, proven surface, active Spec set, witness corpus, and spec diagnostics in one pane. --watch --prove wires the same loop into your editor: hot-swap only on safe / safe_with_additions.

commands zigttp studio dev --watch --prove

05

20 native modules, zero npm surface

Every capability ships as Zig. Imports stay explicit; sandboxes stay derivable from the contract.

modules zigttp:auth zigttp:crypto zigttp:sql zigttp:cache zigttp:durable zigttp:service zigttp:scope zigttp:io + more

06

Contract-aware deploy with a proof ledger

zigttp deploy emits a self-contained binary and appends one row to .zigttp/proofs.jsonl with the proven facts and a verdict against the prior entry. zigttp proofs list | show | diff | export browses, re-renders, diffs, and exports the timeline as markdown, HTML, or an SVG verdict badge.

commands zigttp deploy zigttp proofs zigttp witnesses

Good Questions

The fast objections.

How is zigttp different from Node.js, Deno, and Bun?

Node.js, Deno, and Bun run the full language. zigttp uses zigts, a restricted subset, so the compiler can prove handlers, derive least-privilege sandboxes, and replay runs deterministically. That guarantee needs a closed language surface.

What does "proves your code correct" actually mean?

Three stacked layers, then your own. -Dverify proves seven path properties: returns, reachability, Result narrowing, match coverage, property access, dead code, and contract extraction. Sound mode adds arithmetic and comparison checking across all operators. -Dcontract extracts a behavioral contract that zigttp deploy diffs against the prior version. On top, every Spec<...> obligation you declare (idempotent, deterministic, no_secret_leakage, ...) is discharged by the verifier and surfaced live in zigttp studio.

What happens on a breaking change?

Run with dev --watch --prove and the server diffs the contract on every save. The verdict is one of safe, safe_with_additions, breaking, or needs_review. Only the first two hot-swap; the others block the swap and print the diff. zigts prove old.json new.json runs the same comparison standalone in CI.

What is the witness corpus?

Every counterexample the compiler discovers persists to .zigttp/witnesses/ so a falsifying input never needs to be rediscovered. The corpus replays through zigttp mock --replay, surfaces in the studio panel, and the live-reload HUD calls out when a pinned witness re-fires - that is a regression you explicitly chose to defend against.

Can I use npm packages with zigttp?

No. zigttp ships 20 native zigttp:* modules in Zig (auth, crypto, validate, decode, sql, cache, durable, http, io, router, compose, env, url, id, log, text, time, ratelimit, service, scope) and the compiler tracks every import. If a module does not cover what you need, call the external API with fetchSync.

How do I install zigttp?

Pre-built binaries cover macOS and Linux on x86_64 and aarch64. Current release is v1.0.0-alpha. Building from source requires Zig 0.16.0. 

curl -fsSL https://raw.githubusercontent.com/srdjan/zigttp/main/install.sh | sh
