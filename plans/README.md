## Findings considered and rejected

- **Path traversal in `main.ts:84`**: not a defect. `url.pathname` is
  WHATWG-normalized before the handler sees it, and percent-encoded dots stay
  literal path segments that `Deno.readFile` treats as filenames.
- **Missing response compression**: Deno Deploy compresses at the edge. Not
  worth a plan without a deployed measurement, and guessing at it would be
  inventing a number.
- **Unscoped `--allow-read` in the `start` and `dev` tasks**: tightening to
  `--allow-read=static` is defensible least privilege, but the project has no
  third-party dependencies, so the threat it addresses is not present.
- **`script.js?v=13` bumped while the file is unchanged**: costs returning
  visitors one 7.6KB refetch. Real, and below the bar for a plan.
- **CWD-relative `./static` path in `main.ts:84`**: works under both
  `deno task start` and Deno Deploy. Speculative without a case where it fails.
- **`.svg`, `.woff`, `.woff2` content types with no current consumer**: cheap,
  conventional, and likely to be needed. Removing them is churn. Plan 010
  deliberately removes only the video types, which pair with a CSP directive
  also being removed.

## Areas checked and found clean

Recorded so a later audit does not re-litigate them without new evidence.

- No `innerHTML`, `insertAdjacentHTML`, `outerHTML`, `document.write`, `eval`,
  or `new Function` anywhere in the client JavaScript. The proof card is built
  node by node.
- No inline executable `<script>`, no `on*=` event handlers, no `style=`
  attributes, and no `<style>` blocks in any of the three documents. This is
  what makes plan 003 safe.
- Dead CSS: 256 class selectors across `style.css` and `home.css` checked
  against all markup and JavaScript. Zero unmatched. The one apparent miss,
  `.w3`, is a false positive from the `www.w3.org` namespace inside an SVG data
  URI at `static/style.css:72`.
- Cache-bust versions are consistent across `index.html`, `deck.html`, and
  `404.html`.
- Inactive deck slides are `display: none`, so the `aria-hidden` applied at
  `static/script.js:150` does not strand focusable content.
- The textarea seed in `static/index.html:310-325` matches `SEED_SPEC` in
  `static/playground.js:37-50`.
- Baseline at time of audit, on Deno 2.9.4: `deno fmt --check` (20 files),
  `deno lint` (4 files), `deno check main.ts tests/site_contract_test.ts`, and
  `deno task test` (6 passed) all green.
